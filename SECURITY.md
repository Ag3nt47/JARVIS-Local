# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and the latest published release. Older
builds are not supported; reproduce a report against the newest available version when possible.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting
form](https://github.com/Ag3nt47/JARVIS-Local/security/advisories/new). Do not open a public issue
for a suspected vulnerability and do not include real credentials, personal data, or other
sensitive information in a report.

Include the affected version or commit, a minimal reproduction using non-sensitive fixtures, the
expected behavior, and the observed behavior. The complete application threat model and security
boundaries are documented in [docs/SECURITY.md](docs/SECURITY.md).
